# 2026-07-31 — Starting My Learning Journal

> **Related Topic(s):** Documentation, Markdown, GitHub
> **Related Project (optional):** Learning Journal

---

## What Happened

Today I created my Learning Journal to document my progress throughout the Cloud Engineering and DevOps Bootcamp.

Initially, I planned to organize the repository into folders based on technologies such as Git, Linux, Docker, and AWS.

After thinking about how I would actually use the journal over the coming years, I realized that approach would create unnecessary complexity. Many learning experiences span multiple technologies, making it difficult to decide where an entry belongs.

I decided to keep the journal simple by creating one Markdown file for each meaningful learning experience. Each file will be named using the date followed by a short descriptive title. This approach keeps the journal chronological, easy to navigate, and easy to maintain as it grows.

I also created a reusable journal entry template so every entry follows the same structure while remaining quick to write.



---

## Lessons Learned (Optional)

- Simplicity encourages consistency.
- A Learning Journal should capture meaningful learning experiences, not every study session.
- One entry per file is easier to manage than one large journal document.
- A reusable template reduces friction and keeps entries consistent.
