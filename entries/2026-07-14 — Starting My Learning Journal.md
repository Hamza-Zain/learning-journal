# 2026-07-14 — Starting My Learning Journal

> **Related Topic(s):** Documentation, Markdown, Git, GitHub

---

## What Happened

Today I created my Learning Journal to document my progress throughout my journey to becoming a Cloud and DevOps Engineer.

Initially, I wanted to organize the repository into folders based on technologies such as Git, Linux, Docker, and AWS. However, I realized that this approach would create unnecessary complexity because many learning experiences combine multiple technologies, making it difficult to decide where an entry belongs.

I decided to keep the journal simple by creating one Markdown file for each meaningful learning experience. Each file will be named using the date followed by a short descriptive title.

This approach keeps the journal chronological, easy to navigate, and easy to maintain as it grows.

I also created a reusable journal entry template so every entry follows the same structure while remaining quick to write.

---

## Lessons Learned

- Simplicity encourages consistency.
- Only write when you genuinely have something meaningful to say.
- One entry per file is easier to manage than one large journal document.
- A reusable template makes contributing easier and keeps entries consistent.
