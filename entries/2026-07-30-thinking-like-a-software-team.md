# 2026-07-30 — Thinking Like a Software Team

> **Related Topic(s):** Git, GitHub, Software Development

---

## What Happened

While studying Git and GitHub, I decided to treat my **Scanitta Barcode Scanner Web Application** project for **Bricks Technologies** as a real product rather than a learning exercise. My goal was to develop it using the same workflow that a professional software development team would follow.

One of the biggest insights I gained from doing this was understanding that software projects grow through small, incremental improvements. I also realized that planning, collaboration, code reviews, versioning, and software releases are just as important as writing the code itself.

---

## Lessons Learned

- Software projects grow through small, incremental improvements.
- Organizing a project is as important as writing its code.
- Building realistic projects creates a stronger understanding.
